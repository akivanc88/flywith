# Security Policy

## Reporting a Vulnerability

Please do not open public issues for suspected vulnerabilities.

Report security concerns using GitHub's private vulnerability reporting if it is
available on this repository, or contact the maintainer directly from the
repository owner profile.

Include:

- A short description of the issue.
- Steps to reproduce.
- The affected file, feature, or workflow.
- Whether you believe credentials, signing material, or user data are exposed.
